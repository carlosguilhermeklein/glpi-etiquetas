# Changelog

## 1.2.0

First public release.

- English source strings with Brazilian Portuguese translation.
- Generic default template (entity name, inventory number, description and user; QR code with the asset link).
- Template data uses English keys; installations of 1.1 are migrated automatically.
- Uninstall also removes the uploaded logos.
- Command line renamed to `plugins:etiquetas:generate-pdf`.

## 1.1.0

- Label templates: size, columns, margins, resolution, QR code or Code 128 barcode,
  logo upload and configurable text lines.
- Template selection on the review page.

## 1.0.0

- *Print labels* massive action, review page and PDF for 50 x 20 mm rolls with 2 labels per row.
